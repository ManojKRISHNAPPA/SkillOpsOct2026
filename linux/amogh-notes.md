# Linux Learning Notes

## Basic Linux Commands

1. pwd - Shows the present working directory.
2. ls - Lists files and directories.
3. cd - Changes the directory.
4. mkdir - Creates a new directory.
5. touch - Creates an empty file.
6. cp - Copies files and directories.
7. mv - Moves or renames files.
8. rm - Removes files.
9. cat - Displays file contents.
10. clear - Clears the terminal screen.
